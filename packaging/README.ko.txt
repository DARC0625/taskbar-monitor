Taskbar Monitor 0.4

CPU, RAM, GPU, 디스크, NPU, 팬 상태를 작업표시줄 안에 표시하는 Windows 11 x64용 위젯입니다.

설치와 실행
- 설치 프로그램을 실행하면 현재 사용자용으로 설치됩니다. 기본 설치 위치는 %LocalAppData%\Programs\TaskbarMonitor입니다.
- 설치할 때 바탕 화면 바로 가기와 "Windows 로그인 시 Taskbar Monitor 실행"을 선택할 수 있습니다. 두 옵션은 처음에는 꺼져 있습니다.
- 설치 후 시작 메뉴의 Taskbar Monitor로 실행합니다. 자동 시작 옵션은 설치 프로그램을 다시 실행해 변경할 수 있습니다.
- 위젯이나 알림 영역의 Taskbar Monitor 아이콘을 우클릭하고 "종료"를 선택하면 앱이 종료됩니다.

화면 설정
- "게이지 디자인": HUD 원형 계기, EVA 분절 게이지, Minimal 얇은 원형 중 선택합니다.
- "테마": Windows 테마를 따르거나 밝은 테마·어두운 테마를 선택합니다.
- "표시 항목": 필요한 항목만 켜고 끕니다. 최소 한 항목은 남습니다.
- "위치 · 크기": 조금 왼쪽/오른쪽으로 이동하거나 폭을 조절합니다. 기본 위치는 작업표시줄 왼쪽에서 12DIP이며, 왼쪽 버튼으로 끌어서 이동할 수도 있습니다.
- "기본 배치로 되돌리기"는 위치·폭·표시 항목·테마·디자인을 기본값으로 되돌립니다.
- CPU·RAM·GPU·DISK 등의 하위 메뉴에서 장치 모델과 측정 내용을 확인할 수 있습니다. "센서 다시 확인"은 장치와 측정 기준을 새로 확인합니다.

설정 파일과 포터블 사용
- 일반 설치와 portable.flag가 없는 실행은 %LocalAppData%\TaskbarMonitor\widget.json에 설정을 저장합니다.
- 포터블로 사용하려면 쓰기 가능한 폴더에 배포 파일을 풀고, taskbar-monitor.exe 옆에 빈 portable.flag 파일을 둔 뒤 실행합니다. 이 경우 같은 폴더의 widget.json을 사용합니다.
- 일반 모드에서 새 설정이 없으면 실행 파일 옆의 유효한 구버전 widget.json을 한 번 가져옵니다. 기존 원본 파일은 그대로 남습니다.
- 설정을 직접 수정할 때는 앱을 먼저 종료해 주세요.

제거
- Windows 설정의 "앱 > 설치된 앱"에서 Taskbar Monitor를 제거합니다. 설치 파일·바로 가기·이 앱의 로그인 자동 시작 항목이 제거됩니다.
- 사용자 설정은 재설치를 위해 %LocalAppData%\TaskbarMonitor에 남습니다. 포터블 버전은 앱을 종료한 후 해당 포터블 폴더를 정리하면 됩니다.

표시와 지원 범위
- DISK는 연결된 물리 디스크 중 가장 바쁜 디스크의 활성 시간입니다.
- NPU가 없는 PC는 "장치 없음", 팬 RPM을 제공하지 않는 PC는 "센서 미지원"으로 표시합니다. 지원하지 않는 장치나 센서를 가짜 0%·0RPM으로 표시하지 않습니다.
- "준비 중", "갱신 지연", "조회 오류"는 측정 상태입니다. 드라이버나 하드웨어에 따라 제공되는 항목이 다릅니다.
- 현재 Windows 11의 기본 모니터 가로 작업표시줄을 대상으로 하며, 공식 작업표시줄 확장 API가 아닌 내부 창 구조를 사용하므로 Windows 업데이트나 다른 작업표시줄 도구에 따라 호환성이 달라질 수 있습니다.
