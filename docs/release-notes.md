Windows 11 x64 작업표시줄 모니터의 안정성 업데이트입니다.

- 우클릭 설정에 현재 사용자용 "Windows 로그인 시 자동 실행"과 Windows 시작 앱 설정 바로 가기를 추가했습니다. 설치 프로그램과 같은 등록 항목을 사용합니다.
- 기본 재설치가 앱에서 변경한 자동 실행 선택을 유지하고, 앱에서 나중에 켠 자동 실행도 제거 시 정리하도록 설치 프로그램을 보완했습니다.
- CPU/RAM·GPU·디스크·NPU 수집을 분리하고 종료 대기를 제한하여, 느린 센서가 다른 수집 경로와 종료를 붙잡지 않도록 했습니다.
- 느린 장치 재탐색이 반복되는 기준 시각 처리를 수정하고, 창 해제 전에 수집 알림을 중단합니다.
- 실제 위젯의 최근 지연·자원 사용·복구 이력을 제한된 크기의 진단 보고서로 남길 수 있습니다.
- 설정 크기·형식·너비 경계값 처리와 원자적 저장을 보강했습니다.
- 리셋으로 폐기한 표본이 새 데이터로 집계되지 않도록 수정했습니다.
- 진단 통계의 비유한 수치·역순 표본·큰 값 계산을 보강했습니다.
- CI가 Windows 빌드·방어적 회귀·진단 실행·패키지·설치 수명주기를 검사합니다.
- RustSec 의존성 감사와 CodeQL 분석, 자동 의존성 업데이트를 구성했습니다.
- 기존 위젯을 건드리지 않는 portable 재연결 검사와 PID·시작 시각을 확인하는 장시간 관찰 도구를 추가했습니다. 실제 Windows 11 화면과 장시간 실행 결과는 별도 검증 범위입니다.

설치형 EXE 또는 Portable ZIP을 선택할 수 있습니다. 파일 무결성은 SHA256SUMS.txt로 확인하세요. build-info.json에는 빌드한 소스 커밋과 실행 파일 해시가 있습니다.

기본 모니터의 가로 작업표시줄을 대상으로 합니다. 내부 Windows 창 구조를 사용하므로 Windows 업데이트와 다른 작업표시줄 도구에 따른 호환성은 별도 확인이 필요합니다. NPU·팬은 공급자와 하드웨어 지원에 따라 상태를 표시합니다. 코드 서명은 아직 적용하지 않았습니다.
